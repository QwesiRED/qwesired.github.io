# QwesiRED Security Blog

Personal security research blog for Adam Nurudini (QwesiRED).

## Features

- Dark theme with red accents
- CVE writeups and security research articles
- Terminal-style hero section
- Responsive design
- RSS feed generation
- Static export for GitHub Pages

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Deploy to GitHub Pages

1. Push to GitHub
2. Enable GitHub Pages in repository settings
3. Set source to `out` folder or use GitHub Actions

## Adding Posts

Create a new `.md` file in `posts/` with frontmatter:

```markdown
---
title: 'Post Title'
date: '2026-01-01'
tags: ['Tag1', 'Tag2']
description: 'Brief description'
---

Your content here...
```
